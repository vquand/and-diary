# Diary stickers

Original raster artwork generated for and-diary with OpenAI image generation. Each sticker uses a transparent background, textured ink edges, and watercolor washes. Files are optimized to 128 × 128 PNGs for 24 logical-pixel calendar badges and share GPUI's decoded-image cache. They follow the project's noncommercial license.

Names correspond to the stable Pin IDs in src/pins.rs. Preserve filenames and IDs when replacing artwork so saved dates retain the intended sticker.
