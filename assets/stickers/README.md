# Diary stickers

Original raster artwork generated for and-diary with OpenAI image generation. Each sticker uses a transparent background, textured ink edges, and watercolor washes. Files are stored as WebP images for space efficiency and share GPUI's decoded-image cache. They follow the project's noncommercial license.

Names correspond to the stable Pin IDs in src/pins.rs. Preserve filenames and IDs when replacing artwork so saved dates retain the intended sticker.
